Digital-Detox-Provider is a personal project which create an abstraction
from whatsapp account. In simple terms this project makes it easier for someone to use a custom whatsapp which only shows important messages stripping out statuses and unnecessary chat.
I used a particular API that takes the messsage and send it directly to the whatsapp acoount and the specific user.


Disclaimer: This is for my personal practices to understan how pipeline from across platforms work.
It is unnofficial and not a product,I recommend not using your official whatsapp account so as to avoid being banned/suspended.
